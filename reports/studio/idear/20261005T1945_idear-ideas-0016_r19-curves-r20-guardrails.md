## 摘要与关联结果

R006 把 idear-0015 的根因修复完整落地（r18 零值对照 + r19 复活 = 三方实锤），task 通道激活的发现已入史册。本报告对 r19 的 227 点曲线做量化判读，三点：

1. **Test_Return 口径澄清（防误读）**：R006 §2 称「首次非零回报」——**严格说这是「口径激活」而非「性能提升」**：return tracker 累计 env 奖励，r4-r18 恒 0 正因通道死亡（R006 §2 自己也注明了这点，但 14.6 这个数字容易被误当跨 run 可比量）。r19 的 14.6 只能与 r20+ 比，不能与历史 0 比。真正的跨 run 性能量尺仍是 **EVAL ep_len**（R006 §5.1 正确）。
2. **test_ret × task 负相关（-0.526）**：task 均值升（0.358→0.380）而 test_ret 降（14.6→11.5）。用 task 归一化粗估 ep_len：test ≈ 40 步（Q1）→ ≈30 步（Q4）；train 峰值 ≈74 步（26.7/0.366）。**36% 进度时无突破迹象**——但曲线仅 227 iter（r4 的 95 出现在 3487 iter），不构成 I53 判定（R006 §2 同判）。负相关的三种竞争解释见 I55。
3. **r20 判读护栏补强（I56）**：ep_len 直接日志缺失使本报告只能间接推断（两套归一化假设给出 30-45 步区间）——r20 应把 ep_len 写进日志消除歧义；同时预注册「task 激活后 return 与 ep_len 的换算口径」。

**B. 相关性（已观测，`research/studio/idear/20261005_r19_corr.py`）**：corr(test_ret, task) = **−0.526**；corr(test_ret, smp) = +0.039；corr(task, smp) = **+0.541**。
- task×smp 正相关：策略状态在两奖励下同向改善（贴数据流形）——机制符合预期。
- test_ret×task 负相关：test episode 累计回报下降与训练奖励上升并存——需要解释（I55 三候选）。

**C. ep_len 双口径粗估（推断，非直接观测）**
- 口径 1（return=混合奖励累计，r≈0.59/步）：test 14.6→25 步 / 11.5→19 步；train max 26.7→45 步。
- 口径 2（return tracker=env task-only 累计，r≈task≈0.37/步）：test 14.6→40 步 / 11.5→31 步；train max 26.7→**74 步**。
- 口径歧义来源：`_train_return_tracker` 累计的是 `step()` 返回的 `_reward_buf`（task-only，修复后非零）还是混合值，取决于 tracker 更新在 `_compute_rewards` 覆盖 buffer 之前/之后——**未从源码确认**（worker 一行可查）。两口径都指示 test ep_len 在 19-40 区间，train 峰值 45-74——**36% 进度下尚无 ≥90 的突破信号，但 train 峰值口径 2 的 74 步已超 r14/r17 的 40**（弱积极信号，若口径 2 正确）。

**D. R006 其余要点（已观测，引用）**：I51 accepted 已验证（@fce3a6a）；I52 superseded；全部账号 19-28 耗尽（第 6 次余额击杀，r19@107M/36% 权重丢失）；r20 配方冻结一键启动；P0 历史改写 19 轮纯 SMP。

## 优先建议

### I55 · test_ret 下降的三种竞争解释与最小判别（r20 出结果前的分析准备）
- **关联结果版本**：R006 §2「Test_Return 14.6→11.5 微降而每步奖励上升，或为探索/方差」
- **机制假设**（三候选，不互斥）：
  1. **评估方差/早期波动**：test_episodes=32，30Hz 下 ep_len 30-40 的 episode 的 return 离散度大；且 r19 处于 critic 重适应期（reward 尺度从 ~[0,1] 突变到 ~[0,1.5]，0015-I51 预注册过波动护栏）。**支持迹象**：train_ret 自身波动 1.4-26.7（远大于 test 降幅）。
  2. **探索收缩**：task 奖励给「贴参考」以稠密梯度 → 策略更快进入低熵轨迹 → test（无探索噪声？actor_std FIXED 0.05 下 train/test 差异小）与 train 同降但 test 先显现。**反对迹象**：corr(test_ret, smp)≈0（若整体收缩，smp 通道也应同向）。
  3. **口径效应**：test_ret 的分母/组成在通道激活后改变（C 节两口径），下降是定义变化而非行为变化。
- **最小改动或诊断实验**：r20 曲线出来后做同一分析：若 test_ret 曲线随 ep_len 突破而大涨 → ①方差说成立（早期波动无意义）；若 ep_len 突破而 test_ret 平/降 → ③口径说成立（return 不再是性能代理，弃用）；若 ep_len 与 test_ret 同平台 → 真实学习问题。
- **对照变量**：r20 全程 vs r19 前 227 点。
- **预期指标/支持否定条件**：见三分支。
- **成本风险**：零（分析准备）。
- **worker 的下一步**：R007 判读时按此表归档解释。
