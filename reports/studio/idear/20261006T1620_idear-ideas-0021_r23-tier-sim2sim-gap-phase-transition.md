## 摘要与关联结果

R009 终判 40-90 档（r23=74.88@461M，+228% over r20）。本报告五点：

1. **【证伪结算】0019 的「预算回报率低」先验被推翻**：外推 +8-15% 基于 r22@74%（340M）中途段，而 r23 的跳变发生在 iter>2594 的最后 26%——被杀段的线性外推错过了相变。教训：**训练后期存在「姿态锁定」相变，相变前的曲线斜率对相变后状态无预测力**（r22@340M 的 test_ret 25.2 与 r23 同点 25.7 几乎相同，但 r23 又跑 900 iter 后 EVAL 跳到 74.88）。
2. **「相变时刻随机性」统一模型（本报告核心）**：六点预算-ep_len 全景的非单调性（246M→67 / 300M→40,39,23 / 461M→75,95）在「每个 run 在随机时刻从探索态相变到锁定步态、预算只增加相变机会」模型下统一解释——r6 早运（246M 内相变）、r14/r17/r20 300M 未相变、r4/r23 461M 相变。**推论：run 方差 ±40% 量级是真实的，ep_len 单点值不可作为配方比较依据（需多种子或相变指标）**。
3. **r4 之谜结算**：95（纯SMP@461M）与 74.88（task活@461M）同档——无需隐藏变量；有趣的是 task 通道在 300M 档是负贡献（40→23）、461M 档也是（95→75），两个预算档方向一致（纯 SMP 的 ep_len 更高）——**task 通道换来的是表型质量（v/slip/duty）而非存活长度**（R007 结论的再确认，代价方向现在双向一致）。
4. **【新警示】sim2sim gap 随策略改善而扩大**：Isaac/MuJoCo 存活比 r14=1.40 / r17=1.26 / r20=0.78 / **r23=2.23**——r23 在 Isaac 构型终止推迟到 2.5s（慢速 0.59 易跟参考），但 MuJoCo 纯物理跌倒仍 1.12s。若 gap 系统性存在，**即使 Isaac 达到满时长，MuJoCo 验收（用户最终目标）可能仍卡在 ~1-2s**——这是下一个需要正视的瓶颈，E4 参数扫描的平坦性（pd/fric 都 ~1s）指向引擎级差异（PolySim 文献：单引擎策略零样本迁移率 3.6-50%）。
5. **r24 设计（I74）**：600M 单跑（相变概率最大化，直攻可验收策略）+ Isaac 侧 fall 物理统计（分离「构型终止」与「物理跌倒」，量化 gap 真实大小）+ I64 分桶首次生效（bb759a8 console fix）；多种子方案降为科学归因备选。

## 论文与实现证据

**A. Isaac/MuJoCo 存活比演化（已观测数字，本报告整理）**

| run | 配方 | Isaac ep_len(s)（pose_fail 口径） | MuJoCo(s)（root_h<0.25 纯物理） | ratio |
|---|---|---|---|---|
| r14 | 纯SMP@300M | 1.33 | 0.95 | 1.40 |
| r17 | 纯SMP@300M | 1.31 | 1.04 | 1.26 |
| r20 | task@300M | 0.76 | 0.98 | **0.78**（MuJoCo 反而长） |
| r23 | task@461M | **2.50** | 1.12 | **2.23** |

- 口径差异必须注意：Isaac 判据=相对构型失配（E19），MuJoCo=root_h<0.25（纯跌倒）。**两列不直接可比，但演化趋势可比**：r20 的反转（MuJoCo>Isaac）说明当时 Isaac 侧是「跌倒比构型失配更早触发物理上的失败被 pose_fail 捕捉」；r23 的 2.23 说明 Isaac 构型保持大幅改善而 MuJoCo 物理稳定性未同步。
- I68（R009 §3）：root_h 下降启动 0.70-0.93s——MuJoCo 侧失稳早于 1.12s 的判据触发。

**B. 跳变定位（已观测）**：r22@iter2594 test_ret 25.2（末50均值）≈ r23 同 iter 段 25.7（末窗）——两 run 到 340M 前不可区分；r23 最后 ~900 iter（26%）内 EVAL 跳到 74.88。tracker 口径弱吻合 task-only（25.7/74.88=0.34/步 ≈ 0.4 预期的偏底，R009 §1 同判）。

**C. 预算-ep_len 六点全景（已观测）**：见摘要 2。注意 r6（246M→67.2）高于 300M 所有点——**非单调**；同配方重复（r14 vs r17 = 40 vs 39）方差小，但跨配方/跨预算方差极大——与「相变时刻随机」模型一致（同配方同预算的相变时刻相近时方差小，相变边界处方差爆发）。

**D. R009 其余要点（已观测，引用）**：四方表型（r23 v 0.59 回撤 / slip 0.27 / MuJoCo 1.12±0.21s）；摆幅实测 0.60-0.61m；first-slot 四连验（createTime=15:49:04）；I64 console fix @bb759a8（r24 生效）——I71 判别结果为 logger/console 链（I71-(b) 分支）。

## 反证与不确定性

- **[已观测] 六点全景/存活比表/跳变定位/四方表型/I68**：R009 与历史数据整理，脚本归档。
- **【证伪结算-0019】**预算回报率先验推翻：外推基于被杀段（错过相变）；0019 的其他结论（口径统一建议、通道教训、r21 残值不可判）不受影响。这是本项目第三次预注册证伪（0015 ep_len 断言、0018 相位排除、0019 回报率先验）——预注册结构三次都把证伪约束在预声明分支内，方法本身有效。
- **[推断-中置信] 相变模型**：统一解释六点非单调 + r22/r23 同点不可区分而终值悬殊；但 n=6 且无多种子控制——I76 回溯是廉价检验；竞争解释是「大方差 + 预算阈值带」的混合。
- **[推断-中置信] sim2sim gap 扩大**：口径差异（构型 vs 物理）使两列不严格可比；「gap 扩大」的结论依赖「Isaac 物理存活未同步改善」这一未测假设——I74 双列统计正是裁决；若 Isaac 物理也是 ~1.2s，则 gap 是口径伪影，MuJoCo 1.12s 与 Isaac 物理一致，问题回到「两环境都物理不稳」（训练侧可解）。
- **[推断] task 通道对 ep_len 负贡献（两预算档方向一致）**：n=2 档各 1 对，弱证据；与 R007「task 换表型不换存活」自洽。
- **[说明] 对 R009 的处置**：其判定（40-90 档）与 r4 消解均被本报告采纳并深化；本报告的修正仅在「r24 单点值解释边界」（相变模型）与「gap 警示」两处新增。
