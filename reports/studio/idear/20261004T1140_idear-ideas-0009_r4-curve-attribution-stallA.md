## 摘要与关联结果

三块新证据的判读：

1. **E9 归因分析（r4 全程 3487 iter / 457M samples）——0006-I19 停滞 A 形态实证触发**：
   - Smp_Reward 早期升至峰值 ~0.44（iter 1501–2000 窗口均值 0.436），**随后回落至 0.36 平台**（2501–3000 窗口 0.388、3001–3500 窗口 0.361，尾段 375 点均值 0.361、max 0.392）；
   - **Sds_Loss 在 0.20 处不可约平台**（1501 后 0.232→0.199→0.200，三窗口完全平）；
   - `smp_reward_std/mean` 从 0.92 收缩至 0.36 并稳定——判别力衰减到一个稳定残余；
   - imp_ratio 全程 ~1.0、clip_frac 0.33–0.60——PPO 本身健康，不是优化故障。
   - **结论**：SMP 奖励存在 ~0.44 的结构性上限（对应 normalized loss 下限 ~0.41，exp(−2×0.41)=0.44），与 0006-I19 停滞 A 预测「卡在 0.4–0.5」精确吻合。**机制最可能解释**：流形内滑移分量（数据支撑相滑移 25–35% 编码进先验速度域）物理不可达 → 策略状态即使姿态完美仍有残余 SDS loss。
2. **旧线策略 sim2sim 冒烟（worker 首批 rollout）——策略侧滑移被物理抑制**：
   - 9 episodes（3 配置 × ~3 eps）**全部跌倒**，存活 0.72–0.94 s，fwd_vel 0.59–0.92 m/s，攻角 p50 65–76°（远超 10–25° 标准），duty 极端不对称（SI 0.31–0.47）；
   - **slip_ratio 0.105–0.161**：远低于数据侧 0.25–0.35——策略未继承数据滑移（摩擦约束生效）。
   - **判读**：与停滞 A 完全相容且互补——「策略不滑移（物理禁止）+ 先验期望滑移（流形编码）= 残余 SDS loss → 奖励上限」。注意旧线策略本身是冻结线产物（质量差、1s 内跌倒是预期），这批数据的价值是**管线验证 + 滑移对照**，不是策略结论。
3. **0007/0008 修复确认**：worker 的 `verify_i23.py`（站立 1s contact rate 应 ~1.0）/`verify_i26.py`（稳态延迟==n_delay 步）验证脚本与最新 validator 全量实现（sole_zmin L181–183、STANCE_Z=0.008 L406–410、slip_ratio L414–432、attack_angle L436–446、latency 管线 L343–346）——**R003 的指标有效性前提已齐**。

**对 H-B 的更新**：原 H-B 断言「策略可达域与流形交叠不足 → 冻结」在 r4 解冻后已弱化为「交叠足以启动学习但滑移分量造成奖励上限」；sim2sim 侧新证据（slip 0.10–0.16）表明策略侧滑移不是问题——**问题只在奖励侧（先验流形含不可达状态）**。

### I30 · E6b 优先级恢复：消滑移重投影测试现在是判定停滞 A 机制的最短路径
- **关联结果版本**：idear-ideas-0004/I14（E6b 三层测试）、0005/I17（判读表）；本报告 E9 实证触发
- **文件/函数**：`x1_prior.pt` + 离线脚本（建议 `analysis/`）

- **机制假设**：若把数据窗口支撑相速度重投影（消除滑移，0004-I14 测试 3）后 ESM_SDS_loss 显著下降（如 0.20→<0.10），则机制链闭合：**残余 loss 确由滑移分量贡献 → SMP 奖励上限 ~0.44 结构性成立 → r5+ 的提升路径是数据侧（I16 v3.1 重投影增广）或奖励侧（K 扩高 t/权重重平衡）而非继续训练**。
- **竞争解释**：残余 loss 也可能来自窗口边界效应/EMA 差异/正常化统计漂移——重投影测试可一并排除（若重投影后 loss 不降，则另有源头）。
- **最小改动或诊断实验**：同 0004-E6b 测试 3（~100 行脚本，分钟级推理）；输出：原窗口 vs 重投影窗口的 ESM_SDS_loss 分布（K=[22,15,8] 分别报）。
- **对照变量**：滑移消去比例（全消 vs 半消）；timestep 分层。
- **预期指标**：loss 降幅 >30% 判「滑移主导」；<10% 判「另有源头」。
- **支持/否定条件**：支持停滞 A 机制=重投影后 loss 大降；否定=不降（转查 EMA/normalizer/窗口边界）。
- **成本风险**：低；这是 r5 决策（是否值得做 v3.1 数据/重训先验）的依据。

## 反证与不确定性

- **[已观测] r4 曲线平台 + sds_loss 不可约 0.20**：worker 数据直读，分段统计脚本归档可复现。峰值窗口 0.436 与尾段 0.361 的差（0.075）在 std 0.13 下是真实回落还是窗口采样偏差：尾段 375 点 max 0.392 < 峰值窗口均值 0.436——**回落为真**，但幅度温和（~17%），称「平台微跌」比「崩溃」准确。
- **[推断] 平台 = 滑移分量贡献**：机制链的最后一环靠 I30（E6b' 重投影测试）闭合；当前是两侧证据（奖励上限 + 策略不滑移）的最优解释但非唯一直接证据。
- **[推断] 旧线策略跌倒为预期**：旧线是 r3 冻结线的 10k5 ckpt（R001 §5：Train/Test_Return=0），1s 跌倒与「未学会行走」一致；但也可能有 sim2sim gap 成分——r4 ckpt 的 R003 将把两者分开（r4 若也秒跌则 gap 主导）。
- **[未验证] verify_i23/i26 的实际输出**：脚本存在且逻辑正确，但我未运行（无 mujoco/torch）；以 worker 运行结果为准。
