## 4. 数据质量发现

1. **支撑相滑移**（已观测）：支撑期足端水平位移合计 1.8–5.6 m/段，约为身体前进量的 25–35%。理想刚体接触应≈0（足应世界系锚定）。这是重定向运动学 IK 的遗留（v3 只修了平底/闭合/抖动，未做世界系锚定）。**对策略学习影响推断**：扩散先验会吸收该模式，但物理仿真中摩擦会约束策略实际滑移；风格奖励（SDS）为软约束，不至于阻断稳定步态。属"可训练但风格保真度打折"项。
2. **对称性**（已观测）：step_SI 0.004–0.119，除 run1_s5_seg0（0.119）外均<0.07，可接受。
3. **反相关系数为正**（未验证→方法限制）：步态标准要求臂腿反相 π±0.35，但原始 hip_pitch L/R 相关系数+0.5~+0.85，因为信号混入了 2×步频的垂直起伏同相分量。本指标只能作为代理；严格的反相检验需按步频带通后再算（后续 sim2sim 评估时补）。
4. **关节平滑性**（已观测）：dof 最大速度 ~790°/s、jerk 峰值 ~400 rad/s³（30fps 差分，含量化噪声），未见毛刺；knee ROM 87–111° 在限位内。
5. **速度区间**：源数据 1.2–1.6 m/s 属慢跑；"奔跑"目标（>2 m/s）需策略在物理仿真中超出参考速度范围外推，或将 sprint 族段（README 声明物理不自洽）重新处理。当前 v3 数据集覆盖不足以直接学 sprint。
